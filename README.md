# ממסטיה לאושגולי

אפליקציית טרק בעברית עם ארבעה מקטעי GPX, תחזית לנקודה גבוהה בכל מקטע, מיקום GPS בזמן השימוש ואלבום תמונות משותף. התמונות שהוספתם בזמן ניתוק נשמרות בדפדפן ומסתנכרנות בפעם הבאה שהאפליקציה פתוחה ויש חיבור.

## הפעלה מקומית

דרוש Node.js 22 ומעלה. הריצו `npm run dev` ופתחו `http://127.0.0.1:4173`. התצוגה המקומית זמינה במחשב שמריץ אותה בלבד. תמונות בדיקה נשמרות ב־`.local/album/`. ניתן לבנות את גרסת האירוח עם `npm run build` בפרויקט עם קובץ `.openai/hosting.json`.

## הגדרות פרטיות ופרסום

`trip-settings.local.json` משמש לתצוגה מקומית. בפריסה, הגדירו את תוכנו במשתנה `TRIP_SETTINGS`, הגדירו את מאגר R2 כ־`BUCKET`, והגבילו את האתר לחשבונות של המטיילים. בשרת המאוחסן, כל בקשת אלבום או פרטי טרק דורשת זהות שמאומתת על ידי שכבת האירוח. קריאות מיקום נשארות במכשיר. `bookingOwner` משמש להצגת קישורי אישורי Gmail לחשבון הבעלים בלבד. קישור ישיר שמוזן במסך הלינה נשמר מקומית בדפדפן.

```json
{
  "label": "תאריכי הטרק",
  "bookingOwner": "owner@example.com",
  "days": [
    { "date": "2030-07-01", "stay": "שם מקום הלינה", "booking": "booking-hotel-slug" }
  ]
}
```

לפני היציאה יש לפתוח את היישום בכל מכשיר וללחוץ על **שמירה ללא קליטה**. התחזית מתעדכנת בטווח התחזית ומציגה את מועד השמירה כשאין חיבור. פתיחת אישורים חיצוניים וסנכרון האלבום דורשים אינטרנט. תצוגת המפה מתבססת על קובצי GPX וכוללת מרחק משוער עד סוף המסלול, לפי ההיטל על המקטע שנבחר.

המסלול מבוסס על [Caucasus Trekking](https://www.caucasus-trekking.com/treks/trek-mestia-to-ushguli). תחזית מזג האוויר מגיעה מ־[Open-Meteo](https://open-meteo.com/). קרדיטים ורישיונות צילום מופיעים בתוך האפליקציה.
